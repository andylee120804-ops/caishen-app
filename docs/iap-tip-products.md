## 一句话结论（2026-10-20 拆分后）

App 里两类付费，**现在是两组各自独立的消耗型商品，共 10 个**：

- **打赏（tip_*，5 个）**：纯自愿赠与，进公益排行榜，**不再解锁任何摆件**。
- **装扮/陈设（decor_*，5 个）**：解锁财神殿视觉（灯样式/香炉/殿宇主题/四件陈设），**不进公益榜**。

> 目的：审核能明确区分「打赏」与「装扮购买」，二者合规文案也不同（打赏承诺不承诺祈福效果、
> 装扮仅声明改变视觉效果）。

## ⚠️ 上一版报「模板不正确」的两个根因（已修）

1. **商品类型用了字符串 `consumable`** —— 官方模板商品类型是**数字**：`0`=消耗型 / `2`=订阅 / `3`=非消耗型。10 个商品全部填 **0**。
2. **默认语言写成 `zh-CN`** —— 官方要求**下划线** `zh_CN`（连字符会报错）。

## AGC 批量操作步骤

1. 登录 AGC → **我的项目** → 本应用 → **分发 / 商品管理（IAP）** → **商品**。
2. 点 **批量操作** → **导入商品** → **下载官方「商品模板」**（以官方列名为准）。
3. 把 `docs/iap-tip-products.xlsx`「商品数据」表 **10 行**，按「官方模板对照」表的字段映射复制进官方模板：
   - 商品类型填数字 **0**（消耗型）
   - 默认语言填 **zh_CN**
   - country=CN、currency=CNY、price=8/18/88/188/888
4. 上传导入；已存在商品会按商品 ID 覆盖名称/描述/价格（商品类型创建后不可改）。
5. 冒烟：App 内打赏每一档（公益榜记账）+ 财神殿装扮/陈设每一档解锁均能拉起收银台并消耗成功。
