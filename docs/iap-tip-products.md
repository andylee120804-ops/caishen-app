## 一句话结论

App 里所有付费点 = **打赏（纯自愿赠与）+ 财神殿摆件（装扮/陈设）**，二者**共用同一组 5 个消耗型商品**。
代码已明确约定「摆件复用打赏档、不新建 AGC 商品」，所以 **AGC 只需创建这 5 个商品**，无需为摆件另建。

## ⚠️ 上一版报「模板不正确」的两个根因（已修）

1. **商品类型用了字符串 `consumable`** —— 官方模板商品类型是**数字**：`0`=消耗型 / `2`=订阅 / `3`=非消耗型。5 个商品全部填 **0**。
2. **默认语言写成 `zh-CN`** —— 官方要求**下划线** `zh_CN`（连字符会报错）。

## AGC 批量操作步骤

1. 登录 AGC → **我的项目** → 本应用 → **分发 / 商品管理（IAP）** → **商品**。
2. 点 **批量操作** → **导入商品** → **下载官方「商品模板」**（以官方列名为准）。
3. 把 `docs/iap-tip-products.xlsx`「商品数据」表 5 行，按「官方模板对照」表的字段映射复制进官方模板对应列：
   - 商品类型填数字 **0**（消耗型）
   - 默认语言填 **zh_CN**
   - country=CN、currency=CNY、price=8/18/88/188/888
4. 上传导入；已存在的商品会按商品 ID 覆盖名称/描述/价格（商品类型创建后不可改）。
5. 冒烟：App 内打赏每一档 + 财神殿四件陈设/SignIn 摆件解锁均能拉起收银台并消耗成功。
