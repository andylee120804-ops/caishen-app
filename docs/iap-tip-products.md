## ⚠️ 真正导致「模板不正确」的结构问题（已修正）

AGC 官方模板 `Product_Batch_Adding_or_Modification_Template_v2` 只有 13 列、列名是固定英文字段，且强校验。之前「商品数据」表按 Connect API 拆成多列（`productNo`/`productName`/`defaultLocale`…）且价格只写整数，与官方模板**结构完全不符**，这才是反复报「模板不正确」的根因。关键规则：

1. **语言/名称/简介不是三列，而是合并进 `Locale Title Description` 一列**，格式：`zh_CN|商品名称|商品简介`（默认语言放最前，多语言用 `|` 隔开；名称 1–55 字、简介 1–100 字，名称/简介内禁止出现 `|`）。
2. **价格不是单个数字，而是 `国家;价格` 配对、两位小数**：`CN;8.00`（多国用 `;` 隔开，如 `CN;8.00;DE;1.00`）。
3. **商品类型仍是数字 `0`**（消耗型；`3`=非消耗型、`2`=订阅、`4`=非续期订阅）。
4. **新增必填列**：`Product Sales Scope`（销售范围）填 `CN`；`New Country/Region` 填 `1`（勾选新国家/地区）。币种不单独成列，已包含在价格配对里。
5. 表头行（第 1 行）与**说明行（第 2 行）必须保留**（官方注明"导入时此行不可删除"），数据从第 3 行开始；示例行（testImport01）需删除。

## AGC 批量操作步骤（如需手动重填）

1. 登录 AGC → **我的项目** → 本应用 → **分发 / 商品管理（IAP）** → **商品**。
2. 点 **批量操作** → **导入商品** → 上传 `docs/AGC商品导入模板_已填入.xlsx`（或自行下载官方模板，按下表填）。
3. 上传后预览，确认 10 个商品（消耗型、CN、价格正确）；已存在商品按商品 ID 覆盖名称/描述/价格（类型创建后不可改）。
4. 上架/提交审核；冒烟：App 内打赏每一档（公益榜记账）+ 财神殿装扮/陈设每一档解锁均能拉起收银台并消耗成功。
