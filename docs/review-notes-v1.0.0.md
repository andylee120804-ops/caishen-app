## 一、本版本修复内容（对应审核反馈问题1）

**审核反馈**：应用内含付费项目（解签每日解锁 / 买断），但未在应用内提供客服联系方式，影响用户体验。参考《审核指南》第 11.2 项。

**整改措施**（已在代码中实现并构建通过）：

1. **新增「联系客服」入口**（「我的」页功能菜单，位于「界面定制」下方，始终可见）：
   - 点击弹出「联系客服」弹窗，展示客服邮箱 **andyli0912@petalmail.com**。
   - 提供「📋 复制邮箱」按钮：一键复制客服邮箱到剪贴板，便于用户自行发送。
   - 提供「✉️ 发送邮件」按钮：调用 `startAbilityByType("mail", ...)` 拉起系统邮件应用，预填收件人 / 主题 / 正文，用户只需补充问题描述即可发送。
   - 弹窗内注明「工作日 48 小时内回复」，明确响应承诺。
2. **隐私政策补充客服邮箱**：原「如对本隐私政策有任何疑问，请联系开发者」改为「请联系客服：andyli0912@petalmail.com」，应用内 PrivacyDialog 与隐私政策全文文档已同步更新。

**技术说明**：
- 发送邮件使用 HarmonyOS 官方推荐的 `startAbilityByType("mail", wantParam, callback)`（API 12+），`wantParam` 含 `sceneType: 1`（发送意图）、`email`（收件人，URL 编码）、`subject`、`body`。
- 若设备未安装邮件应用，`onError` 回调捕获失败并提示用户改用「复制邮箱」手动发送，不会静默失败或崩溃。

## 五、应用内购买（IAP）付款路径说明

本应用本版本仅保留一类付费：华为应用内购买（IAP）**消耗型商品 · 支持作者**；财神殿付费陈设已隐藏。

### 路径一：支持作者（tip_*，纯自愿赠与）

**审核员操作路径**：
底部导航「**我的**」Tab → 页面中部「**支持作者**」卡片（副文案「支持作者的一份心意 · 部分所得用于公益」）→ 弹窗内选择档位 →「**支持作者 ¥X**」→ 华为收银台付款。

| 商品 ID | 价格 | 档位名 |
|---|---|---|
| tip_8 | ¥8 | 支持 · 心意 |
| tip_18_2 | ¥18 | 祝愿 · 顺遂 |
| tip_88_2 | ¥88 | 福田 · 同行 |
| tip_188 | ¥188 | 厚意 · 圆满 |
| tip_888 | ¥888 | 至诚 · 厚爱 |

**合规说明**：支持作者为对开发者的**自愿赠与**，款项用于应用后续开发与维护（部分捐赠公益，可在「公益明细」页查看）。**不承诺任何祈福效果，不解锁任何应用权益**；付款后商品即时消耗（finishPurchase），不影响任何功能可用性。付款记录进入云端公益榜（donation-record 云函数，purchaseToken 幂等去重）。

**代码位置**：`entry/src/main/ets/pages/MyPage.ets`（入口）→ `entry/src/main/ets/components/DonateDialog.ets`（档位/支付流程）→ `entry/src/main/ets/service/IapPaymentService.ets`（purchaseTip / consume）→ `entry/src/main/ets/service/IPaymentService.ets`（TIP_PRODUCTS）。

### 路径二：财神殿付费陈设（本版本已隐藏）

**2026-10-27 审核整改**：财神殿内的四件付费陈设 / 装扮入口已全部从界面移除，本版本**不提供任何 decor_* 商品购买入口**。财神殿仅保留：
- 免费点香（心意值经每日进殿等行为获取，不涉及付费）；
- 「写下祈福话 → 生成电子祈福图 → 保存到手机」（纯本地生成，免费）。

相关实现代码仍保留在 `DecorPayDialog.ets` / `HallViewModel.ets`，待后续方案明确后再考虑启用。

### 免费功能：电子祈福图

- 操作路径：底部导航「**财神殿**」→ 点击香炉上香 → 点击「**写下祈福话 · 生成祈福图**」→ 输入祈福话 → 生成 → 在 6 套传统风格模板中切换（朱砂金榜 / 宣纸墨金 / 黛蓝鎏金 / 青绿山水 / 绛紫祥云 / 玄黑鎏金）→ 点击系统「**保存图片**」安全控件保存到手机相册。
- 该功能完全免费，不与任何付费档位绑定；生成和保存均在本地完成（保存使用系统安全控件，不额外申请相册写权限）；用户上次选择的模板会保存在本地偏好中。
- 代码位置：`entry/src/main/ets/pages/CaiShenHallPage.ets`、`entry/src/main/ets/components/BlessingImageDialog.ets`。

### 支持作者付款路径的共同点（供审核参考）

- 走华为 IAP 消耗型商品，付款走系统收银台，开发者不接触支付信息；
- 支付成功 → 云端记账 → finishPurchase 消耗；未完成订单（含崩溃恢复）由 queryPurchases(UNFINISHED) 自动补单；
- 未登录华为账号 / 地区不支持 / 商品未发布等前置错误均有明确 toast 引导，不向用户暴露错误码。
