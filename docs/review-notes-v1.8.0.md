# 版本 1.8.0 提审说明（AGC Review Notes）

> 提交版本：**1.8.0（versionCode 1000010）**
> 适用对象：华为 AppGallery Connect 审核员
> 本文档为审核辅助说明，不随应用打包，供提审时在「版本说明」中参考。

## 一、本版本整改内容（祈福页面整体下线）

**审核反馈**：应用不允许出现祈福页面。

**整改措施**（已在代码中实现并构建通过）：

1. **祈福 / 还愿 Tab 下线**（2026-11-04 整改）：底部导航固定首位改为「财神殿」；「还愿」入口整体下线，「界面定制」入口池同步剔除。
2. **求签页「去祈福」入口移除**（2026-11-15 整改）：签文揭晓操作行与解签详情弹层的两处「去祈福」按钮全部隐藏，求签流程不再跳转任何祈福页面。
3. **还愿「磕头还愿」入口隐藏**：心愿条目的「还愿」按钮（磕头动画入口）不再展示。
4. **「祈福排行榜」入口下线**：从功能入口池与「界面定制」中移除，底栏与「我的」页均不可见。
5. 祈福流程相关页面（写祈福话 / 磕头祈福 / 祈福完成页）代码保留在工程中便于后续版本恢复，但**本版本应用内无任何可达入口**，审核员在应用内无法进入任何祈福页面。

## 二、当前应用功能范围（供审核员核对）

**可用功能**：

- 财神殿（免费）：点香互动（心意值免费获取）、「写下祈福话 · 生成电子祈福图 · 保存到手机」（纯本地生成、免费，不与任何付费绑定）；
- 求签：每日 3 签、摇晃出签、签文详解 / 签运速览 / 今日建议全部免费，无付费墙；
- 电子木鱼、运势·黄历、收支记录（记账工具）；
- 我的：支持作者（自愿赠与）、公益明细、联系客服、隐私政策、界面定制。

**本版本不提供的功能**：祈福流程页面、还愿、祈福排行榜（均无入口，见上文整改措施）。

## 五、测试建议

1. 进入求签页摇晃出签 → 签文揭晓后确认**无「去祈福」按钮**，操作行仅「解签详情」「再求一签」。
2. 点击「解签详情」→ 弹层底部确认**无「去祈福」按钮**，仅「复制签文」。
3. 「我的」→「界面定制」→ 确认入口池中**无「还愿」「祈福排行榜」**。
4. 财神殿：点香免费、可生成电子祈福图并保存；确认**无任何付费陈设购买入口**。
5. 「我的」→「支持作者」→ 华为收银台付款流程正常；「公益明细」可查看记录。
6. 「我的」→「联系客服」→ 邮箱展示 / 复制 / 发送邮件均可用。
7. 首次启动弹出「隐私政策」，正文开头有「加速度传感器使用说明（目的 / 方式 / 范围）」段落，
   「一、我们收集的信息」含「加速度传感器数据」条，「三、权限说明」含
   「加速度传感器（ohos.permission.ACCELEROMETER）」条；「我的」→「隐私政策」可再次复阅。
